# MediVault

## Emergency Medical Record Access System

MediVault is an Android-based emergency medical record management application designed to provide quick and controlled access to important medical information during emergencies.

## 📱 About the Project

MediVault allows users to securely manage their medical information, emergency contacts, medical records, and important medical documents.

The application also provides an Emergency QR system that allows authorized emergency information to be accessed quickly while keeping protected medical records secure.

## 🔄 Application Workflow

1. User registers an account.
2. User logs into MediVault.
3. User creates an emergency medical profile.
4. User adds emergency contacts and medical records.
5. User uploads important medical documents.
6. User generates an Emergency QR code.
7. An emergency person can scan the QR code.
8. Only selected emergency information is displayed.
9. Protected medical records remain restricted.
10. Emergency access can be recorded in access history.

## 🔒 Security

MediVault separates emergency information from protected medical records.

The Emergency QR system is designed to provide limited emergency information without exposing the user's complete medical records.

Firebase Authentication and Firestore are used to manage user authentication and application data.
